## Project

Phased portfolio website showcasing GitHub projects (GitHub user `Shubhankar9934`). Served by nginx in Docker and exposed via ngrok. Phase 1 (static site) is built; Phase 2+ adds a FastAPI + PostgreSQL backend. `demo.txt` is unrelated Graph RAG notes.

**Start here for context:** read `tasks.md` (what is done / next) and `decisions/README.md` (index of ADRs), then open only the ADRs you need. Record every new non-trivial decision as the next numbered ADR in `decisions/` (use `decisions/template.md`), add it to the index, and update `tasks.md`.

## Commands

Run from `web/` unless noted:
- `npm run dev` - Vite dev server
- `npm run build` - typecheck (`tsc --noEmit`) + production build to `web/dist`
- `npm run lint` - ESLint
- `npm run sync` - refresh `data/github-stats.json` from the GitHub API (never fails hard; keeps old data on error)

From the repo root (Docker Desktop must be running):
- `docker compose up -d --build web` - build and serve the site at http://localhost:8080
- `docker compose --profile tunnel up -d` - also start ngrok (needs `NGROK_AUTHTOKEN` and `NGROK_DOMAIN` in `.env`; copy `.env.example`)
- Health check: `curl localhost:8080/healthz`; reserved API stub: `curl -i localhost:8080/api/health` (503 until Phase 2)

There is no test suite yet.

## Architecture

- All UI reads project data through the `ProjectsSource` interface in `web/src/data/source.ts`, chosen by `VITE_DATA_SOURCE` (only `static` exists). Phase 2 adds an API-backed source there; do not import `projects.json` directly from components.
- Content is JSON in `web/data/`: `projects.json` (curated), `github-stats.json` (generated by the sync script, merged in `web/src/data/staticSource.ts`), `profile.json` (bio, skills, experience, education, `resumeUrl`).
- Docker build context is the repo root (`web/Dockerfile` copies `docker/nginx/default.conf`), not `web/`.
- nginx (`docker/nginx/default.conf`): SPA fallback, hashed assets cached 1y, `index.html` no-cache, `/api/` reserved. Locations use `expires` rather than `add_header` because `add_header` in a location drops the server-level security headers.
- Theme is set before first paint by an inline script in `web/index.html`; `web/src/theme/useTheme.ts` syncs React to it.

## Working rules

- Ask the user for permission before creating any folder or directory, including folders created implicitly by scaffolding tools or by writing a file to a new path.
- Do not invent personal facts (experience, education, contact details) in `profile.json`; leave them empty until the user supplies them (ADR-0011).
